HANDINVERT — WEB VERSION

This is a separate HandYT-style project. Instead of showing YouTube, it inverts
the camera image colors inside the four-corner area between the thumb and index
fingertips of both hands.

To publish:
1. Create a GitHub repository named HandInvert.
2. Upload index.html to the repository root.
3. Open Settings -> Pages.
4. Choose Deploy from a branch, branch main, folder /(root), then Save.
5. Open the HTTPS Pages URL on your phone or PC and allow camera permission.

HTTPS is required for browser camera access. Internet is required to load
MediaPipe and its hand tracking model. Keep both hands visible.
